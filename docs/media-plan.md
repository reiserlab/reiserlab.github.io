## 3. Processing spec

| Asset | Spec |
|---|---|
| Paper figure | Export the panel from the publisher's high-resolution figure or the lab's original file. Crop to 3:2. Master PNG at ≥ 2400 px wide in `media/figures/`. The build writes WebP at 400, 800, 1600 px. |
| Loop video | 6–12 s cut, 1280 px wide, MP4 (H.264, CRF 23, no audio) and WebM (VP9 or AV1), under 2 MB each, plus a JPEG poster frame. `muted autoplay loop playsinline`, paused when off-screen and under `prefers-reduced-motion`. |
| Scroll hero frames | 150–240 frames; desktop WebP/AVIF at 1920 px wide, ~60–120 KB each; mobile set at 960 px. Portrait-safe framing. Poster frame plus reduced-motion static fallback. |
| Portraits | Color, 3:4 crop, 1200 px tall master, same lighting if possible (schedule one lab photo session a year). |
| Credits | Every file has an entry in `media/credits.yaml`: source (paper DOI, figure, movie number, or "lab, unpublished"), creator, license, any required attribution text. The build renders a credits page from it. |
